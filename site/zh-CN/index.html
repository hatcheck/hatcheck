从账号配置开始

Claude Code 把登录、设置和会话保存在一个文件夹中。让 CLAUDE_CONFIG_DIR 指向另一个文件夹，就会得到拥有独立登录的配置。Codex 和 Kimi Code CLI 分别使用 CODEX_HOME 和 KIMI_CODE_HOME。Hatcheck 的 cl、cx 和 ck 会按固定路径启动它们：

cl work              # 使用 ~/.claude-work；首次运行时会要求登录
cl personal          # 使用 ~/.claude-personal 和另一个账号
cx work login        # 使用 ~/.codex-work 登录 Codex
ck work login        # 使用 ~/.kimi-code-work 登录 Kimi Code CLI
cd ~/code/api
hatcheck bind work   # 在此项目中，cl、cx、ck 默认使用 work 配置
hatcheck             # 查看此项目在所有配置中的会话和用量

直接运行 claude、codex 或 kimi 仍使用各自的默认文件夹。Hatcheck 不读取、复制或移动登录，也不会自行切换账号。

项目工作区和会话库

项目工作区

固定常用项目，查看绑定配置、最近会话和缓存用量。新会话必须明确选择智能体、配置和文件夹；绑定冲突会阻止启动，绝不会静默换号。

会话收藏和筛选

收藏会话、添加个人别名和标签、归档而不删除。按智能体、配置、模型、费用、标签、日期和收藏状态筛选，并保存为命名视图。标签只保存在 Hatcheck 自己的 library.json 中。

移动、备份和导出

在账号或智能体之间移动或复制会话。移动前可查看保留和遗漏内容、创建会话文件备份，并在桌面应用中撤销同智能体移动。支持 Markdown、独立 HTML 和 JSON 导出。

hat workspaces add ~/code/api --name API
hat open --new work --cwd ~/code/api   # 明确选择 work，在项目中开始新会话
hat -o claude,codex -i agy            # 只看 Claude/Codex，排除 agy
hat search "登录 重试"                 # 搜索会话标题和对话
hat export --project ~/code/api --hours 3d --format html --output ~/hatcheck-exports

套餐和本地用量分析

hat u 显示各套餐剩余额度、重置时间和消耗速度；hat b 只提供账号建议，不会启动或移动会话。hat insights 使用本地历史，生成用量曲线、可能提前用尽或用不完的预测，以及按配置、项目和模型汇总的费用。

hat u                       # 各套餐的剩余额度
hat b                       # 账号建议，仅此而已
hat insights --days 7       # 最近一周的本地分析，不请求实时接口
hat doctor --deep           # 检查会话、绑定、启动器、重复进程和存储

桌面应用的“用量”页还有曲线图、预测卡片和费用排行。没有读数会明确显示为未知，不会被当作零用量。

每个账号一个 Claude Desktop

在 macOS 和 Windows 上，每个实例都有独立的数据文件夹和登录，以及不同颜色的启动器。启动器会把正在运行的实例带到前台，而不是重复打开同一个配置。

hatcheck desktop new work "Work" --hue 190       # 蓝色启动器
hatcheck desktop new hp-bot "HP Bot" --hue 110   # 绿色启动器
hatcheck desktop open work                       # 打开或置于前台
hatcheck desktop                                 # 查看实例及运行状态

首次打开时，在每个实例中分别登录。绿色等颜色用于启动器；运行中的 Dock 图标仍由 Claude 自己提供。

桌面应用与简体中文界面

菜单栏（Windows 和 Linux 为系统托盘）显示额度、最近会话和桌面实例。主窗口提供工作区、会话库、导出、用量图表和配置管理。按 Ctrl/Cmd+K 打开命令面板，方向键选择，Enter 运行，Esc 关闭；该快捷键仅在应用内生效。

在 Settings → Language 中选择 Simplified Chinese，或选择 System language 跟随系统。命令、选项、配置名、路径、JSON 字段和复制的命令不会被翻译。

从其他工具继续

Raycast、Alfred 和 VS Code 集成通过同一个稳定的 JSON 接口浏览会话和缓存用量。只有在选择“继续”后才会启动终端。

安装命令行工具

macOS、Linux 或 Windows 上只需一个二进制文件，无需 Python：

curl -LsSf https://github.com/hatcheck/hatcheck/releases/latest/download/hatcheck-installer.sh | sh
brew install hatcheck/tap/hatcheck  # 也可以在 macOS 或 Linux 上使用 Homebrew

安装程序只安装 Hatcheck，不安装任何智能体，也不修改它们的配置。完整安装方式和 PowerShell 命令见安装说明。
