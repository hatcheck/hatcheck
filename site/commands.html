Every command

What hatcheck --help prints, then each command's own --help, as 0.7.1 prints them, each with its short form beside it (every command in a few letters). The docs have each command as it is, with examples and its --json.

🎩 hatcheck: Claude Code, Codex, Antigravity CLI, Kimi Code CLI, ZCode, DeepSeek
Harness, MiniMax Code, Qwen Code, GitHub Copilot CLI and OpenCode accounts on one
computer, each kept apart. Lists recent sessions with the command that resumes
each one or opens DSH's session history, what's left of each plan, and carries
sessions between accounts and agents.

Usage:
    hatcheck [sessions] [HOURS] ...    recent sessions in every profile and home, with
                                       resume commands and plan usage (the default)
    hat check ...                      the same as hat (or hatcheck): the name in two words
    hatcheck usage ...                 plan usage left for every profile and home
    hatcheck where SESSION             where a session is stored, by its ID or the start of it
    hatcheck move [SESSION] [PROFILE]  move a session to another profile or home, or convert
                                       it for another of the agents; with a profile alone,
                                       the newest session started here goes to it, and
                                       with nothing, to the best account now, after asking
    hatcheck fork [SESSION] [PROFILE]  fork a session into another profile or home: a new
                                       session with its own ID, and the original stays
    hatcheck relocate OLD NEW          bring the sessions of a project folder that was moved
                                       or renamed along to its new place
    hatcheck open [SESSION] ...        resume a session in a new terminal, in its folder;
                                       for DSH, open dsh web and its session history
    hatcheck resume [SESSION]          carry on the newest session started here, in this
                                       terminal, after asking; hat r for short
    hatcheck show SESSION              a session's conversation, read-only
    hatcheck search WORDS...           the sessions whose title or conversation has every
                                       word, in every profile and home, newest first
    hatcheck best [--for SESSION]      the best account now, in full, and the move command
                                       that carries the newest session started here to it;
                                       --wait sleeps until one has room
    hatcheck bind PROFILE ...          tie a folder to a profile, for cl, cx, ck and the list
    hatcheck unbind [FOLDER]           untie it again
    hatcheck desktop ...               Claude Desktop instances on macOS and Windows: list,
                                       open, make one
    hatcheck provider ...              the Z.ai, Kimi, MiniMax and DeepSeek keys and models
                                       behind claude-z, -k, -m and -d, and cl -z, -k, -m, -D
    hatcheck profiles [A B]            what each profile and home is set up with: skills,
                                       agents, commands, plugins, hooks, MCP servers,
                                       settings; with two named, what differs between them
    hatcheck statusline ...            a status line for Claude Code, with the profile and
                                       what's left of its plan; --install PROFILE adds it
    hatcheck doctor                    every copy of hatcheck and the agents on your PATH,
                                       which runs, and how to remove the rest
    hatcheck completions SHELL         the completions for zsh, bash, fish or PowerShell

hatcheck, usage, where, show, search, profiles, desktop, move, fork, relocate and
doctor take --json, for scripts, status bars and the desktop app.

`hatcheck SUBCOMMAND --help` lists a subcommand's options, and hatcheck --version
says which version this is. hat is the short name: hat usage is hatcheck usage,
and so on. cl, cx and ck run Claude Code, Codex and Kimi Code CLI with a profile.

A subcommand can be cut to its first letters: hat m is hat move, hat f is hat
fork. Where two share a letter, it goes to the one used more: b is best, s is
show, se is search, u is usage, d is desktop, p is provider and r is resume, so
bind, unbind and doctor take two letters, bi, un and do, relocate three, rel,
and profiles four, prof.
hatcheck sessionsor plain hat, the default: recent sessions in every profile and home, with resume commands, costs and plan usage 
usage: hatcheck sessions [-h] [-n N] [-a] [-A | --this-folder] [-f |
                         --no-full] [-C] [-d | --no-details] [-c | --by-time]
                         [-q | --usage] [-j] [-e]
                         [hours]

List recent Claude Code CLI sessions across all ~/.claude* profiles, Codex CLI
sessions across all ~/.codex* homes, Antigravity CLI sessions from
~/.gemini/antigravity-cli, Kimi Code CLI sessions across all ~/.kimi-code*
homes, ZCode sessions from ~/.zcode, DeepSeek Harness sessions across all
~/.dsh* homes, MiniMax Code sessions across all ~/.minimax* homes and the
homes MINIMAX_DATA_DIR and MAVIS_DATA_DIR select, Qwen Code sessions across
all ~/.qwen* homes and the home QWEN_HOME names, GitHub Copilot CLI sessions
across all ~/.copilot* homes and the home COPILOT_HOME names, and OpenCode
sessions from ~/.local/share/opencode, with the command that resumes each one
or opens DSH's session history.

positional arguments:
  hours               how far back to look (default 24); accepts 36, 1.5, 12h
                      or 3d

options:
  -h, --help          show this help message and exit
  -n, --per-folder N  show only the newest N sessions per folder (default:
                      all)
  -a, --all           also list sessions last used from Claude Desktop or the
                      SDK, Codex sessions from the Codex app, its IDE
                      extension or codex exec, the Antigravity app's
                      conversations, Qwen Code sessions from its channels,
                      scheduled tasks and other hosts, and Copilot sessions
                      from clients other than its CLI
  -A, --all-folders   list every folder, from one that has sessions or one
                      that has none
  -f, --full          print CLAUDE_CONFIG_DIR=... claude instead of the cl
                      shortcut, CODEX_HOME=... codex instead of cx, and
                      KIMI_CODE_HOME=... kimi instead of ck
  -C, --cached        take plan usage from the snapshots Claude Code and Codex
                      last saved, and hatcheck's last readings of agy's /usage
                      and Kimi's usage, instead of the APIs
  -d, --details       under each session, its turns and what it spent, by
                      model and kind of token, with the durations its agent
                      wrote down
  -c, --by-cost       the costliest sessions and folders first, instead of the
                      newest
  -q, --no-usage      leave plan usage out
  -j, --json          print the sessions, and the accounts behind them, as
                      JSON for scripts and apps
  -e, --email         with --json, include each account's email address
hatcheck usageor hat u: plan usage left for every profile and home 
usage: hatcheck usage [-h] [-C] [-e] [-j]

Show how much of each plan limit is left, for every Claude Code profile
(~/.claude*), Codex home (~/.codex*), Antigravity CLI folder
(~/.gemini/antigravity-cli) and Kimi home (~/.kimi-code*); ZCode, DeepSeek
Harness (~/.dsh*), MiniMax Code (~/.minimax*), Qwen Code (~/.qwen*), GitHub
Copilot CLI (~/.copilot*) and OpenCode (~/.local/share/opencode) are listed
with why they give none, with mcode's plan quota not wired yet.

options:
  -h, --help    show this help message and exit
  -C, --cached  don't call the APIs; show the snapshots Claude Code and Codex
                last saved, and hatcheck's last readings of agy's /usage and
                Kimi's usage
  -e, --email   show each account's email address (hidden by default)
  -j, --json    print the accounts and their limits as JSON, for scripts and
                status bars
hatcheck bestor hat b: the best account now, and the move command that carries a session to it 
usage: hatcheck best [-h] [--for SESSION] [-C] [--wait [PROFILE]]

The best account now, shown as hatcheck usage shows it, and the hatcheck move
command that carries a session to it: the newest started from this folder, or
--for's. Advice only: it never starts, moves or switches anything.

options:
  -h, --help        show this help message and exit
  --for SESSION     the session to carry: its ID, or the start of it (default:
                    the newest session started from this folder)
  -C, --cached      don't call the APIs; use the snapshots Claude Code and
                    Codex last saved, and hatcheck's last readings of agy's
                    /usage and Kimi's usage
  --wait [PROFILE]  wait until an account has room, then answer: any account
                    of the session's agent (Claude Code's, without a session),
                    or PROFILE's (NAME, default, codex, codex:NAME, agy, kimi,
                    kimi:NAME, dsh, dsh:NAME, mcode, mcode:NAME, qwen,
                    qwen:NAME, copilot, copilot:NAME, opencode)

hatcheck searchor hat se: the sessions whose title or conversation has every word, in every profile and home 
usage: hatcheck search [-h] [--since HOURS] [--here] [--from PROFILE] [-a]
                       [-m N] [-f] [-j]
                       [words ...]

Find the sessions whose title or conversation has every word, in every profile
and home of every agent: newest first, each with the command that resumes it
and the turns the words are in. Case doesn't matter, and a word can be part of
a longer one.

positional arguments:
  words           the words to look for

options:
  -h, --help      show this help message and exit
  --since HOURS   only sessions active in the last HOURS: 36, 1.5, 12h or 3d
  --here          only sessions started from this folder
  --from PROFILE  only this profile or home: NAME, codex:NAME, kimi:NAME and
                  so on, or a path
  -a, --all       also look in sessions from Claude Desktop, the SDK, the
                  Codex app and the other hosts the session list hides without
                  --all
  -m, --max N     show at most N sessions (default 20; 0 for every one)
  -f, --full      print CLAUDE_CONFIG_DIR=... claude instead of the cl
                  shortcut, and the same for the other launchers
  -j, --json      print the sessions found as JSON
hatcheck moveor hat m: move a session to another profile or home, or convert it for another agent 
usage: hatcheck move [-h] [--from PROFILE] [--keep] [--brief] [-y] [--dry-run]
                     [-j]
                     [session] [profile]

Move a Claude Code, Codex, Antigravity CLI, Kimi Code CLI, ZCode, DeepSeek
Harness, MiniMax Code, Qwen Code, GitHub Copilot CLI or OpenCode session to
another profile, to carry on with it there, or convert it for another agent.
With a profile alone, the newest session started from this folder goes to it;
with nothing, or a session alone, to the best account of its agent now, as
hatcheck best picks it; either after asking, unless --yes.

positional arguments:
  session         the session ID, or the start of it (default: the newest
                  session started from this folder; one word that names a
                  profile is PROFILE)
  profile         where it goes: NAME for ~/.claude-NAME, default or claude
                  for ~/.claude, codex for ~/.codex, codex:NAME for ~/.codex-
                  NAME, agy for ~/.gemini/antigravity-cli, kimi for ~/.kimi-
                  code, kimi:NAME for ~/.kimi-code-NAME, zcode for ~/.zcode,
                  qwen for ~/.qwen, qwen:NAME for ~/.qwen-NAME, dsh for
                  ~/.dsh, dsh:NAME for ~/.dsh-NAME, mcode for ~/.minimax,
                  mcode:NAME for ~/.minimax-NAME, copilot for ~/.copilot,
                  copilot:NAME for ~/.copilot-NAME or opencode for
                  ~/.local/share/opencode, or a path (default: the best
                  account of the session's agent now, as hatcheck best picks
                  it)

options:
  -h, --help      show this help message and exit
  --from PROFILE  the profile or home to take it from, when more than one has
                  it
  --keep          keep the original, which copies the session rather than
                  moving it (a converted session's original is always kept)
  --brief         for a conversion into another agent, hand over a brief in
                  place of the whole conversation: the first prompt, the files
                  and commands its tool calls named, and its last turns
  -y, --yes       don't ask: go ahead with the session and account it picks,
                  and in a terminal resume it right after
  --dry-run       show what would be moved, copied, converted and deleted, and
                  change nothing
  -j, --json      say what was or would be done as JSON, and never ask to
                  resume it

                  mcode:NAME for ~/.minimax-NAME, copilot for ~/.copilot,

hatcheck completionsor hat c: the completions for zsh, bash, fish or PowerShell

Print the completions for a shell: the subcommands, each one's options, and,
where a word is a profile, a session or a folder, those, asked of hatcheck as
