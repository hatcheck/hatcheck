Small integrations, the same stable JSON

Browse sessions and cached plans from Raycast, Alfred or VS Code. Nothing starts until you choose it. Nothing reads a login, refreshes a token or runs a background service.

Raycast: recent sessions

Add integrations/raycast/hatcheck-sessions.sh to your Raycast script-command folders, with its assets/ folder beside it, and make it executable. Hatcheck: Recent Sessions lists the last week's sessions and resume commands. Its optional argument selects one agent.

Alfred: searchable sessions

Create a Script Filter that runs /usr/bin/env python3 /absolute/path/to/integrations/alfred/hatcheck_sessions.py {query}. Results filter by title, agent, profile, folder and model. The main action opens the resume command in a terminal; Command copies the command and Alt shows the raw session JSON.

VS Code: sessions and usage

Start an Extension Development Host:

code --extensionDevelopmentPath="$PWD/integrations/vscode-hatcheck"
  • Hatcheck: Resume a Session: search, then resume in a terminal, copy the command or copy the raw JSON.
  • Hatcheck: Cached Plan Usage: the cached usage report in a document.
  • Hatcheck: Local Usage Insights: the structured local report, formatted as JSON.

The extension has no runtime npm dependencies. Its hatcheck.pathHATCHECK_BIN overrides it there and in the other integrations.
