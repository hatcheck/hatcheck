Guides

One page per question, in plain words: how it works without hatcheck first, then what hatcheck adds. What hatcheck never does is the same on every page: it never asks for, reads, copies or moves a login, runs nothing in the background, and switches no account on its own.

  • Two Claude accounts on one MacA Claude Desktop per account, each with its own login and an icon in its own colour, in three commands.
  • Claude Code with two accountsA profile per account, the launcher that runs one, and one list of every profile's sessions and plan usage.
  • Codex CLI with two ChatGPT accountsA home per account, and its sessions and limits beside Claude Code's.
  • Kimi Code CLI with two accountsA home per account, and its sessions and plan windows beside the others'.
  • Claude usage limits: what's left of each planThe 5-hour, weekly and per-model limits, how Claude Code reports them, and every account's in one list.
