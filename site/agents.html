Which agents, and how far

Claude Code, Codex and Kimi Code CLI get a profile per account and a launcher. Antigravity CLI and ZCode keep one login in one folder, which only HOME moves, so hatcheck reads that folder: their sessions are listed, shown and converted, not moved between profiles. DeepSeek Harness gets homes selected by DSH_HOME, read-only: its own profiles are plugin stacks, not hatcheck account homes, and there is no DSH launcher. Each agent's page in the docs says what is read, and the version it was checked against. To install one, see Get the agents, below.

Claude Desktop instances are Claude's, on macOS. relocate brings Claude Code and Codex sessions along with a moved folder; the others' stay as they are, including DSH's immutable folder and workspace state.

Get the agents

Hatcheck installs none of them: each comes from its maker, as a CLI and a desktop app. Hatcheck is built around the CLIs, so install the ones you use; Claude Code, Codex and Kimi Code CLI then sign in once per account, through a profile (start with a profile per account). In a terminal, on macOS and Linux:

curl -fsSL https://claude.ai/install.sh | bash                # Claude Code: claude
curl -fsSL https://chatgpt.com/codex/install.sh | sh          # Codex: codex
curl -fsSL https://antigravity.google/cli/install.sh | bash   # Antigravity CLI: agy
curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash  # Kimi Code CLI: kimi

On Windows, in PowerShell:

irm https://claude.ai/install.ps1 | iex
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
irm https://antigravity.google/cli/install.ps1 | iex
irm https://code.kimi.com/kimi-code/install.ps1 | iex

ZCode's CLI comes inside its app, which puts no zcode command on your PATH. Hatcheck lists ZCode's sessions without one; to run their resume commands, add a short wrapper. DeepSeek Harness installs its dsh command with npm install -g @deepseek-ai/dsh. Once hatcheck is installed, hat do lists each agent on your PATH, its version and which copy runs. The desktop apps:

Claude Desktop with Claude Code in it: macOS, Windows, Linux (beta) ChatGPT with Codex in it: macOS, Windows, Linux (preview) Antigravity macOS, Windows, Linux Kimi Code Desktop macOS, Windows, Linux ZCode macOS, Windows, Linux (beta) DeepSeek Harness CLI, Desktop and source releases

With Homebrew on macOS: brew install --cask claude-code codex antigravity-cli for those CLIs, and brew install --cask claude chatgpt antigravity zcode for the apps.
