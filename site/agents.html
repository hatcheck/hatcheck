Which agents, and how far

Claude Code, Codex and Kimi Code CLI get a profile per account and a launcher. Antigravity CLI and ZCode keep one login in one folder, which only HOME moves, so hatcheck reads that folder: their sessions are listed, shown and converted, not moved between profiles. DeepSeek Harness gets homes selected by DSH_HOME, read-only: its own profiles are plugin stacks, not hatcheck account homes, and there is no DSH launcher. MiniMax Code gets homes selected by MINIMAX_DATA_DIR, and Qwen Code homes moved whole by QWEN_HOME, both read-only, with direct session resume and no launcher. Each agent's page in the docs says what is read, and the version it was checked against. To install one, see Get the agents, below.

Claude Desktop instances are Claude's, on macOS. relocate brings Claude Code and Codex sessions along with a moved folder; the others' stay as they are, including DSH's immutable folder, mcode's shared SQLite state and manifest paths, and qwen's transcripts, filed under the folder's name.

Get the agents

Hatcheck installs none of them: each comes from its maker, as a CLI and a desktop app. Hatcheck is built around the CLIs, so install the ones you use; Claude Code, Codex and Kimi Code CLI then sign in once per account, through a profile (start with a profile per account). In a terminal, on macOS and Linux:

curl -fsSL https://claude.ai/install.sh | bash                # Claude Code: claude
curl -fsSL https://chatgpt.com/codex/install.sh | sh          # Codex: codex
curl -fsSL https://antigravity.google/cli/install.sh | bash   # Antigravity CLI: agy
curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash  # Kimi Code CLI: kimi
npm install -g @deepseek-ai/dsh                               # DeepSeek Harness: dsh (needs Node.js)
curl -fsSL https://filecdn.minimax.chat/public/install.sh | bash # MiniMax Code: mcode
curl -fsSL https://qwen-code-assets.oss-cn-hangzhou.aliyuncs.com/installation/install-qwen-standalone.sh | bash # Qwen Code: qwen

On Windows, in PowerShell:

irm https://claude.ai/install.ps1 | iex
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
irm https://antigravity.google/cli/install.ps1 | iex
irm https://code.kimi.com/kimi-code/install.ps1 | iex
npm install -g @deepseek-ai/dsh
irm https://filecdn.minimax.chat/public/install.ps1 | iex
irm https://qwen-code-assets.oss-cn-hangzhou.aliyuncs.com/installation/install-qwen-standalone.ps1 | iex

ZCode's CLI comes inside its app, which puts no zcode command on your PATH. Hatcheck lists ZCode's sessions without one; to run their resume commands, add a short wrapper. DeepSeek runs DSH with npx @deepseek-ai/dsh web; installed as above, it's the dsh command hatcheck's open commands run. MiniMax Code installs into ~/.minimax-code, separate from its ~/.minimax data home. Qwen Code's installer puts qwen in ~/.local/bin; npm install -g @qwen-code/qwen-code@latest and brew install qwen-code install it too, and its home is ~/.qwen. Once hatcheck is installed, hat do lists each agent on your PATH, its version and which copy runs. The desktop apps:

Claude Desktop with Claude Code in it: macOS, Windows, Linux (beta) ChatGPT with Codex in it: macOS, Windows, Linux (preview) Antigravity macOS, Windows, Linux Kimi Code Desktop macOS, Windows, Linux ZCode macOS, Windows, Linux (beta) DeepSeek Harness macOS (Apple silicon), Windows MiniMax Code CLI and desktop: macOS, Windows Qwen Code Desktop macOS, Windows, Linux

With Homebrew on macOS: brew install --cask claude-code codex antigravity-cli for those CLIs, and brew install --cask claude chatgpt antigravity zcode for the apps.
