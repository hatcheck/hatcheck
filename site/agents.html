Which agents, and how far

Claude Code, Codex and Kimi Code CLI get a profile per account and a launcher. Antigravity CLI and ZCode keep one login in one folder, which only HOME moves, so hatcheck reads that folder: their sessions are listed, shown and converted, not moved between profiles. Each agent's page in the docs says what is read, and the version it was checked against.
